# Security

A flaw in this contract is a security issue even before any code implements it. That
includes any way the contract lets a server:

- learn a password;
- read a vault;
- tell whether an address has an account;
- link one person across services.

Report such issues privately through GitHub's **Security → Report a vulnerability** on this
repository. The organisation-wide policy is
[`.github/SECURITY.md`](https://github.com/EON-Extensible-Open-Network/.github/blob/main/SECURITY.md).
